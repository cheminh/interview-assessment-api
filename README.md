# MU AKS Advanced Rest API

Notes:

- This `mu-aks-a-starter-api` project only has 1 endpoint `~/api/v1/provinces-territories` which is used by the `mu-aks-a-starter-api` project.

- All instructions are located in the following [Application Deployment](https://github.com/manulife-university-global/mu-aks-a-labs-deployment) lab.



Install dependencies:

```bash
npm install
```


Run application:

```bash
npm run start
```


Once the application is running on your local machine, navigate to the following URL to pull up some data:
- http://localhost:4000/api/v1/provinces-territories
